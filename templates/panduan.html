NL2SQL Agent

Sistem AI multi-intent yang mengubah pertanyaan bahasa manusia menjadi query database, grafik, insight, statistik, dan laporan — secara otomatis.

Apa itu NL2SQL Agent?

NL2SQL Agent mengubah pertanyaan bahasa natural menjadi SQL, mengeksekusinya, lalu menjalankan post-processor cerdas sesuai niat user — visualisasi, insight AI, statistik pandas, perbandingan, laporan PDF, atau cek kualitas data.

Input (Bahasa Natural)

"Tampilkan grafik dan jelaskan rata-rata nilai per kelas"

Output (Multi-komponen)

→ SQL query (otomatis)
→ Grafik bar chart
→ Statistik: mean, std, min, max
→ Insight AI 3-4 poin
→ Tombol export PDF/Excel/CSV

Intent Classifier — 9 Intent

Sebelum SQL dibuat, sistem menentukan niat user. Intent menentukan post-processor mana yang dijalankan setelah eksekusi SQL.

Fitur-Fitur Utama

🧠 Data Insight Generator

LLM membaca DataFrame dan menghasilkan 3-4 insight penting: tren, pola, nilai ekstrem, anomali. Dipicu otomatis oleh intent insight, comparison, dan report.

📈 Statistical Helper

Pandas menghitung statistik deskriptif (mean, median, std, min, max) dari kolom numerik — tanpa memanggil LLM. Cepat dan deterministik. Dipicu oleh intent statistic dan report.

📊 Comparison Mode

Kata kunci "bandingkan" atau "vs" memicu intent comparison. Sistem generate chart perbandingan otomatis dan LLM menulis penjelasan perbedaan antar entitas yang dibandingkan.

📑 Report Generator

"Buatkan laporan" atau pertanyaan multi-step memicu intent report. Menghasilkan tabel + grafik + insight AI + statistik + tombol export CSV, Excel, dan PDF langsung di chat.

💬 Follow-up Context Memory

Riwayat 6 giliran percakapan terakhir dikirim ke LLM di setiap request. Query lanjutan seperti "yang di atas 80 saja" atau "urutkan dari terbesar" merujuk konteks query sebelumnya secara akurat.

🔍 Data Quality Checker

Pandas menganalisis DataFrame untuk mendeteksi: nilai null, baris duplikat, dan nilai outlier menggunakan metode IQR (Interquartile Range). Diberi skor kualitas 0-100.

⚡ Multi-step Task Orchestrator

Sistem mendeteksi secara otomatis jika pertanyaan mengandung 2+ kelompok fitur sekaligus. Contoh: "tampilkan grafik dan jelaskan datanya" (fitur visual + fitur analisis = 2 kelompok) → otomatis dieksekusi sebagai report yang menjalankan semua post-processor secara berurutan.

Multi-Model Support

Sistem mendukung 4 model AI dari 2 provider berbeda. Bisa diganti langsung di sidebar tanpa restart server.

⚡ Groq (LLaMA)

LLaMA 3.1 8B Instant

Ringan, sangat cepat. Cocok query sederhana dan penggunaan sehari-hari.

LLaMA 3.3 70B Versatile

Akurasi tinggi. Cocok query kompleks dengan banyak JOIN dan subquery.

✦ Anthropic (Claude)

Claude Sonnet 4.6

Cerdas dan seimbang. Unggul untuk query kompleks, insight mendalam, dan penjelasan detail.

Claude Haiku 4.5

Efisien dan hemat. Performa cepat untuk query sehari-hari dan penggunaan tinggi volume.

Role-Based Access Control (RBAC)

RBAC memberikan hak akses berbeda berdasarkan peran. Semua aktivitas dicatat di audit log.

👤 Role: user

  • ✅ Boleh: SELECT, semua fitur analisis
  • ❌ Ditolak: INSERT, UPDATE, DELETE, DROP
  • 📊 Akses penuh ke: chart, insight, statistik, laporan
  • 🎯 Cocok untuk: siswa, pegawai, analis data

🛡️ Role: admin

  • ✅ Boleh: semua operasi SQL
  • ⚠️ Operasi berbahaya: butuh konfirmasi + EXPLAIN
  • 📋 Semua aksi tercatat lengkap di audit log
  • 🔒 Bisa aktifkan Demo Mode (blok semua non-SELECT)
